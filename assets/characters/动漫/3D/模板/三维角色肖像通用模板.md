# 三维角色肖像通用模板

适用于以已确认的人物图片为身份参考，制作细腻的三维动漫角色胸像。替换方括号中的内容即可使用。

## 可直接复制的生成指令

```text
请根据参考图制作一张高质量三维角色肖像。

【参考图用途】
图1是人物身份的唯一依据，保留其脸型、下颚、五官比例、
年龄感、发型和辨识特征。
图2（如有）仅用于参考渲染质感、光线和色彩，
不借用图2人物的五官、脸型或身材。

【角色与造型】
角色：[姓名、年龄、性别]
发型：[颜色、长度、分缝、刘海或碎发特征]
服装：[服装款式、颜色、材质]
配饰：[耳饰、项链等，并注明左右位置]
神态：[安静自然／温柔／冷静／自信]
严格保持身份参考中的面部特征，不进行通用化美化。

【构图与比例】
单人胸口以上肖像，接近正面，镜头位于眼睛高度。
完整显示头顶，头顶上方保留约8%留白，双肩完整入镜。
保持参考中的头部与肩宽比例，避免广角透视变形。
面部清楚、突出，背景简洁。

【面部质感】
延续参考中的三维动漫风格。
眉骨、眼窝、鼻翼、脸颊、嘴唇与下巴之间有细腻、
连贯的明暗过渡，体现自然体积。
眼睑具有轻微厚度，睫毛根部清晰但不过度浓密；
虹膜层次和眼睛反光克制。
嘴唇保留细微纹理，边缘柔和。
皮肤有细微色彩变化，明暗自然，不蜡质、不油亮、
不过度磨皮，不用粗糙毛孔堆砌真实感。

【头发与服装质感】
头发按照整体发型、大型发束、细小发束逐层组织，
少量碎发自然透光，避免黏连和杂乱线条。
衣物表现真实的织物纹理、厚度、接缝与受力褶皱。
皮肤、头发、布料和金属具有各自不同的反光特征。

【灯光与背景】
使用[柔和暖色窗边侧光]，配合适度补光。
暗部保留细节，亮部不过曝，发丝边缘有克制的透光。
背景为[低对比、轻微虚化的室内环境]，
色彩衬托人物，不抢夺面部注意力。

【约束】
不改变人物身份，不放大眼睛、不缩小鼻子、
不削尖下巴、不加厚嘴唇、不改变年龄感。
避免浓妆、塑料皮肤、玻璃珠眼睛、过强锐化、
泛白轮廓、涂抹痕迹和饰品变形。
无文字、无水印、无界面元素。

优先级：人物辨识度 > 比例与构图 > 材质细节 > 氛围效果。
```

## 已有肖像的修改指令

```text
以已确认的肖像为母版，本次只调整【具体项目】。
人物面容、头肩比例、发型及未指定的造型继续沿用母版。
```

## 使用说明

- 每次尽量提供同一张已确认的身份参考，避免反复使用未经确认的修改结果导致面容偏移。
- 身份参考与质感参考分别注明用途；没有第二张参考图时，删除图2相关说明。
- 配饰左右位置应明确采用人物自身左右还是画面左右。
- 模板用于统一表现方式，参考图用于固定人物身份；生成结果仍需检查面容、比例与细节一致性。
